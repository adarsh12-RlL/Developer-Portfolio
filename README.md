## 📖 Overview

**Developer-Portfolio** is an engineered solution developed by [Adarsh Gokhe](https://github.com/adarsh12-RlL). Built with performance, privacy, and maintainability in mind, this project delivers robust workflows and scalable design patterns.

---

## ✨ Key Features

- **Responsive Modern Design**: Fully responsive across mobile, tablet, and widescreen desktop displays.
- **Interactive UI Components**: Smooth scrolling navigation, project filtering cards, and contact form modal.
- **Lightweight & Fast**: Pure vanilla HTML5, CSS3, and JavaScript with zero heavy framework overhead.

## 🛠️ Tech Stack & Architecture

- **Primary Languages/Frameworks**: STATIC_WEB
- **State & Data**: Modular persistence / APIs
- **Code Quality**: ESLint, strict TypeScript/Python typing, modular directory structure

## 🚀 Getting Started

### Prerequisites
- Git installed on your system



### Download & Installation

```bash
# 1. Clone the repository
git clone https://github.com/adarsh12-RlL/Developer-Portfolio.git
cd Developer-Portfolio

# 2. Open index.html in any modern browser or use Live Server:
# e.g. python -m http.server 8000
```

---

## ⚙️ Configuration & Security

All sensitive values (API keys, database connections, webhooks) must be configured via environment variables.

> 🔒 **Security Note**: Never commit actual secrets to version control. Use the provided `.env.example` as a template and keep `.env` in your `.gitignore`.
